--- title: "Multiple Regression in R" author: "Kelvin Mugwe" date: '2023-09-26' output: pdf_document --- ```{r setup, include=FALSE} knitr::opts_chunk$set(echo = TRUE) ``` **Multiple Linear Regression** This is a regression type of more than one independent variables It follows the equation : $$ y=B0+B1X+B2X2 $$ For this example we will use the Lung Capacity Data set ```{r} print(LungCapData) ``` We will now create a linear model for the data and name it mod1 with dependent variable being the Lung Capacity and independent variables being Age and Height ```{r} mod1 <- lm(LungCap ~ Age + Height) ``` To generate the summary ```{r} summary(mod1) ``` ```{r} summary(mod1) ``` From the data we can find the regression equation $y=-11.747065+0.126368X1+0.278432X2$ Also from the data we see that R\^2 = 0.843 meaning that there is 84 % variation in lung Capacity can be explained in our model. To calculate pearson correlation between Age and Height ```{r} cor(Age,Height,method="pearson") ``` From the correlation we see that there is a positive relationship between Age and Height To find the confidence interval at 95 % confidence level ```{r} confint(mod1,level=0.95) ``` To generate a plot of the regression equation ```{r} plot(mod1) ``` To draw the Anova Table for the regression model ```{r} anova(mod1) ```
